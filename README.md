# Password Generator 🔒  

A simple Python script to generate strong, random passwords based on user preferences.  

## Features  
- Generate passwords of custom length.  
- Include or exclude:  
  - Uppercase letters.  
  - Numbers.  
  - Special characters.  
- Copy the generated password to the clipboard for easy use.  

## Requirements  
- Python 3.6+  
- Install the `pyperclip` library:  
  ```bash
  pip install pyperclip
